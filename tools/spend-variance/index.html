Proof of Work · Spend Variance

Spend Variance & Renewal Tracker.

Unmanaged vendor contracts leak money quietly: spend drifts above forecast, invoices arrive that do not match the PO, and renewal notice dates pass while nobody is watching. This tracker is the control system for all three. A contract register holds the portfolio; a monthly forecast-versus-actual sheet flags any contract running hot; an invoice audit log checks invoiced amounts against POs; and a live dashboard rolls it up — total annual contract value, how many contracts have a renewal notice date on or before the 90-day horizon (including any already overdue), year-to-date forecast versus actual, and how many items are flagged for review. Every vendor name and dollar in it is sample data — the file says so itself.

Directions: Start on the Contract Register and add or edit a contract (annual value, start and end dates, owner, status). The renewal notice date calculates itself — end date minus 60 days. Enter monthly forecast and actual OpEx on the Actual vs Forecast sheet; any line beyond ±10% variance flags REVIEW. Log invoices on the Invoice Audit Log; invoiced amounts that do not match the PO flag REVIEW with the disparity shown. The Dashboard totals everything live.

Inputs, logic, limits

Inputs: contract register rows; monthly forecast and actual OpEx per contract; invoice PO, invoiced, and accrued amounts. Logic: variance = actual − forecast, flagged REVIEW when |variance %| exceeds 10%; invoice disparity = invoiced − PO, flagged MATCH or REVIEW; renewal notice date = end date − 60 days; the dashboard counts contracts whose notice date is on or before today plus 90 days (including any already overdue). Limits: the 60-day notice period is fixed in this tool, not a setting you can change, and there is no day-by-day countdown to a deadline — the dashboard's 90-day count is the horizon view. All data is sample data.
