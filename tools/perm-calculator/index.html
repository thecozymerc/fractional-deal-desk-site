Proof of Work · Pricing Engines

Perm Calculator.

One deal, structured several ways at once. This is the working workbook I used to price enterprise deals: each option tab builds the same deal a different way — an upgrade path, a deeper discount, more seats, vouchers instead of a straight cut — and a compiled tab lines the versions up, so the difference between structures is a number, not an argument.

Below is the actual workbook — all 22 tabs, scrubbed: every name and link from the working file has been replaced with a sample label, and the figures are the model's own, kept so the calculations run end to end. Pick an option tab and change the inputs — list price, the partner-margin factor, the extra-discount factor, the term in months, the seats — and the tab answers with the price after margin, the paying price, the price per user per year, the cost per license, and the annual and total contract values, plus the seat tallies and the differences. The factors are how the real model speaks: you type 0.65 and it means 35% off. So nobody has to learn that dialect to read this sheet, the page says it in plain words beside every factor, and the translation updates as you type. The Compiled Results tab gathers the totals and per-SKU sections from the option tabs in one place, and the Summary tabs draft the approval summary from the numbers. The first tab, START HERE, is the sheet's own instructions, in its own words.
