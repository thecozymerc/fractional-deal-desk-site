How — It works

Three steps, browser-first execution, and clear limits

Three-step review workflow

1. Add the contract — upload a TXT, PDF, or DOCX, or paste the text. 2. Run the analysis: the key facts come out, dangerous shapes raise explicit risk flags with the exact sentence that triggered them, and each of the 51 checks reports found (with the line it came from) or not found, so the gaps are as visible as the catches. 3. Run the AI read for the summary a person would write: what this contract is, the terms that matter, what looks one-sided, and what is missing.

Privacy: the scan runs entirely in your browser — your document never leaves your device, and nothing is stored. The AI read is the one exception: if you run it, the text is sent to the AI endpoint to write the summary. Scanned image PDFs will not read — the file has to carry real text, the same limit the original tool has.

Where this tool comes from

This began as my own working MVP in October 2025 — upload a contract, extract the text, scan for the clauses that matter. This page is that tool rebuilt for the site and finished: the original six scans preserved exactly, a full 51-point tech-contract coverage checklist, a deterministic flags layer that surfaces dangerous indemnity and commercial shapes, and the AI read wired in. It is a first-pass instrument, the way I start a review — it finds the language, flags risky shapes, and marks what is missing. It is not legal advice, and it does not replace reading the document.

Heuristics locate language; they do not judge enforceability. Every raised flag and found item displays the surrounding excerpt from your document so a reviewer can verify context directly.
