S6-P03 · Contract Operations — Tool 13

Contract Analyzer

Drop in a contract and see what is actually in it: the key facts pulled out, every standard item checked for, and a plain-English read of what to watch.

This began as my own working MVP in October 2025 — upload a contract, extract the text, scan for the clauses that matter. This page is that tool rebuilt for the site and finished: the original scans, a full 33-point coverage checklist, and the AI read wired in. It is a first-pass instrument, the way I start a review — it finds the language and flags what is missing. It is not legal advice, and it does not replace reading the document.

How — It works

1. Add the contract — upload a PDF or DOCX, or paste the text. 2. Run the analysis: the key facts come out and each of the 33 checks reports found (with the line it came from) or not found, so the gaps are as visible as the catches. 3. Run the AI read for the summary a person would write: what this contract is, the terms that matter, what looks one-sided, and what is missing.

Privacy: the scan runs entirely in your browser — your document never leaves your device, and nothing is stored. The AI read is the one exception: if you run it, the text is sent to the AI endpoint to write the summary. Scanned image PDFs will not read — the file has to carry real text, the same limit the original tool has.
