Contract Migration & Triage Tracker

Moving contracts from one system to another is where migrations quietly stall: a stage slips, an owner is unclear, a target date moves and nobody flags it. This tracker is the control sheet for that work — one row per migrating contract with where it is moving from and to, its stage, owner, target date, and status, a Risk Flag that reacts the moment a status changes, the metadata that matters when the contract comes back up (governing law, effective date, auto-renewal, liability cap), and a priority tier the operator assigns. Behind it sit the governance references: an approval-routing matrix by discount band, a RACI matrix for the work itself, and an exception log. Every customer, contract, and figure in it is sample data.

Provenance & Operating Record: Built from 15+ years in commercial contracts, deal desk, and revenue operations across contracts up to $300M and 3,000+ SKUs under management. This workbook is an equivalent sample built in October 2026 to pair with the Contract Migration & Deal Desk Transformation Framework portfolio document — the framework itself is a document and no workbook version existed. The site build added the typed metadata columns (Governing Law, Effective Date, Auto-Renewal, Liability Cap) and the Tier column. Tier is assigned by the operator — nothing on this page extracts terms from contract documents and nothing is auto-tiered. All customers, contracts, and figures below are fictional sample data.

Directions

Each row is one contract migration (sample data): where it is moving from, where it is going, its stage, owner, and target date. Change a row's Status and watch the Risk Flag react — set a migration to At Risk and the flag flips to REVIEW; mark it Complete and the flag reads Done; anything else reads Monitor. Use the Approval Routing table to see who must approve at each discount band, and the RACI Matrix to see who owns each step of the work.

Inputs, logic, limits

          
Inputs: The tracker row fields — Contract ID, Customer, From System, To System, Migration Stage, Owner, Target Date, Status, Governing Law, Effective Date, Auto-Renewal, Liability Cap, and Tier — all typed in or selected by hand. Nothing on this page extracts terms from contract documents, and Tier is assigned by the operator rather than auto-tiered.

          
Logic: The only live logic is the Risk Flag formula and the count-by-tier summary (plus the REVIEW, Done, and Monitor counts from those flags). The Approval Routing and RACI tables are static references and the Exception Log is a record, not a calculator.

          
    
            
  • IF Status = "At Risk" → "REVIEW"
    • 
            
  • ELSE IF Status = "Complete" → "Done"
    • 
            
  • ELSE → "Monitor"
    • 
            
  • Count by Tier: exact match per Tier option
    • 
          

          
Limits: Sample data only — six contracts and three exceptions on load. There is no dashboard or velocity roll-up in this workbook, and the page does not promise one.
