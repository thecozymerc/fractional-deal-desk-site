# Fractional Deal Desk & Contract Management — the site

The public site for Lucky's fractional deal desk and contract management practice, built page by page from the sitemap.

**Live pages (Option B launch, Nov 8, 2026):**
- `/` — Homepage (P01): the story, the proof strip, the working pricing embed, featured tools, the booking route.
- `/tools/deal-pricing-solver/` — S6-P01.a, the Deal Pricing Calculator: new-deal pricing, old-vs-new comparison, per-use / per-token lines, coupons, usage-threshold concessions.
- `/tools/perpetual-to-saas-conversion/` — S6-P01.b, the Perpetual-to-SaaS Conversion Calculator.

More pages plug into this same repository as they are built — Services & Pricing, About, the Tools hub, and the rest of Section 6 — following the sitemap. Every page is mirrored in the Drive repository ("Site — Code & Pages (GitHub mirror)") with its text in a Page Text Sheet.

Static site, no build step. Hosted on Cloudflare Pages from this repository.
